# Otimizador-de-entregas - Mini-projeto
Projeto desenvolvido especialmente para a aula de Sistemas Lineares

## O que este projeto vai propor
Criaremos um sistema para otimizar o uso de espaço para remessas de uma empresa de logística, que deseja realizar entregas de ítens com o intuito de maximizar seu lucro, sem exceder a capacidade máxima das unidades da frota

## Por que este projeto?
O propósito deste projeto é desenvolver um sistema que solucione problemas relacionados ao algoritmo *mochila*, abordado na na matéria de **programação linear**. 

## O que este projeto fará
Este projeto resolverá um problema de um cenário fictício para fins de aprendizado.

## Que cenário é este?
Uma pequena empresa de logística, cuja frota é composta por camionetes, deseja otimizar as entregas por remessa, respeitando a capacidade de itens por caçamba e o peso que cada veículo suporta, de tal forma a maximizar o lucro. As camionetes suportam até **600kg** de peso e conseguem levar **6** itens no máximo.
